Connection help

Open this site directly in desktop Chrome or Edge. Connect the ESP32 using a USB data cable, close Arduino Serial Monitor, and choose its serial port. Firmware must send one JSON object per line at 115200 baud.

Keep the browser running and laptop awake while recording. The website does not collect data when closed.
